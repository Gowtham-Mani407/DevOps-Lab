nohup:

* Its the process of running the task or program in the background
* nohup -> keep running after termimal /ssh disconnects
* eg : command -> $ nohup python3 -u pyprogram.py >> dataprocess.log & ( dataprocess.log we just added to see logs )
* & symbol -> run the command in the background

* to check the background things running we can use three types
  -> top - it shows all background tasks like taskmanger
  -> ps - process status
  -> ps -Aux - its shows more preciesly 
  -> ps -Aux|grep dataprocess.py -  it shows the exct output like pattern matching.

 tail -f dataprocess.log -> it will show the realtime printing logs
* tail -10 dataprocess.log -> it shows last 10 items

* kill the background process using this cmd
  $ kill -9 163778(program number)

Change Mode :
* Giving permission to read and write

table fyr:

permission  | symbol |value

read        |    r   | 4
write       |    w   | 2
execute     |    x   | 1

6 -> 4+2 = rw -> read and write 
5 -> 4+1 = r-x -> read and excecute
= -> no persmisson 

eg : chmode 755 datafile.txt

7 -> user  -> rwx
5 -> Group ->  r-x
5 -> otheres -> r-x
