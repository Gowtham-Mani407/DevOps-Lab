normaly if you run any python or java application it  will run in local host :8080

Now put Nginx in front in our application:

1. Create a site configuration:
  
  - sudo nano /etc/nginx/sites-available/networking-lab

  put in networking-lab:

   server {
    listen 80;

    server_name localhost;

    location / {
        proxy_pass http://127.0.0.1:8080;
    }
}

2. Enable the configuration

  -> sudo ln -s /etc/nginx/sites-available/networking-lab /etc/nginx/sites-enabled/networking-lab
  
3. Test the Nginx configuration
  -> sudo nginx -t   -> syntax is ok and test is successful

4. Reload Nginx -> sudo systemctl reload nginx
 then -> curl http://localhost -> will get output in terminal

5 . now if you run the python3 pyscript.py
    Nginx will forward the request to http://127.0.0.1:8080 instead of localhost:8080

   127.0.0.1:8080 -> it also called localhost

proxy_set header:

 -> proxy-pass -> where should i send the request.
 -> proxy-set-header -> what info should i send along with the request


eg:

server {
    listen 80;

    server_name localhost;

    location / {
        proxy_pass http://127.0.0.1:5000;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
