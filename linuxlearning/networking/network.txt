OSI with internet works:

eg : http:// example.com

-> simplified  sequence:

1. Browser neeed the IP address
2. DNS find the IP
3. Browser connects theb server
4. This establish the Http encryption
5. Browser sends the Http request
6. server sends Http response
7. Browser displays the page

important layers:

-> layer 7 -> Application -> HTTP , HTTPS , DNS , SSH -> eg : Get/user
-> layer 4 -> Transport -> protocols -> TCP , UDP -> TCP gives relaible connection , http commonly operates on TCP
-> layer 3 -> Network -> network -> IP
-> layer 2 -> Datalink 
-> layer 1 -> physical


overview:

1.Application
  -> HTTP/HTTPS/DNS

2. Transport
  -> TCP/UDP

3.Network
  -> IP

4.physical
  -> actual network hardware/signals
